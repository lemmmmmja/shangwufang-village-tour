# Shangwufang village tour

Interactive photogrammetric village archive, prepared for GitHub Pages.

In repository **Settings → Pages**, set the build source to **GitHub Actions**. The **Publish village tour** workflow verifies and extracts the website payload, then publishes it. The workflow can also be started from the **Actions** tab.

在仓库 **Settings → Pages** 中选择 **GitHub Actions**。发布流程会校验并解包完整网站，再生成可分享的网址。后续更新需完整替换 `payload/` 中的分卷和清单。
